# Practice: 50 easy LeetCode problems

Every problem here is LeetCode "Easy". They're in order: each stage only needs the pages you've read so far.

## How to do one problem

1. Open the practice file, for example `1-numbers-and-if/01-2235-add-two-integers.py`. The top of the file explains the problem in plain words.
2. Write your code inside the function, where it says `# your code here`.
3. Run it:

    ```bash
    python3 01-2235-add-two-integers.py
    ```

    Each test prints ✓ (right) or ✗ (wrong, with what you returned and what was expected).
4. All ✓? Open the LeetCode link, paste your `class Solution`, and press **Submit**.
5. Stuck for more than 20 minutes? Read the hints at the bottom of the file. Still stuck? Open the same file in `../solutions/`.

Put an `x` in the box (`[x]`) when you've solved one.
