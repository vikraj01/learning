# Practice list: 50 easy problems

Fifty beginner problems that teach you Python by using it. Do them in order: each stage only needs the lessons before it.

They come from two sites. **GfG** is GeeksforGeeks; these are from its "Basic" level (the easiest it has) and its Python practice set. The LeetCode ones are the few that almost everyone solves (85% or more of attempts pass). Make a free account on both.

On either site, choose **Python3** as the language. Tick the box when you've solved one.

Stuck for 20 minutes? Look back at the lesson. Stuck for 40? Read the hints or solutions on the site, close them, and write it yourself.
