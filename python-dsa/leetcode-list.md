# Practice list: 50 easy problems

Fifty easy problems that teach you Python by using it. Do them in order: each stage only needs the lessons before it.

Click a problem to open it. On LeetCode, choose **Python3** in the language menu. Tick the box when you've solved one.

Stuck for 20 minutes? Look back at the lesson. Stuck for 40? Read the hints or solutions on the site, close them, and write it yourself.
