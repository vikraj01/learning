# Python for problem solving

This folder teaches you Python from zero, up to the point where you can solve easy LeetCode problems on your own.

The plan is simple: learn a little, then solve problems with it straight away. You learn Python by using it, not by reading about it.

## How it works

1. Read a page in `learn/`. Each page is one idea and takes about 10 minutes.
2. Run the matching example in `learn/examples/` and change things in it.
3. When a page says "practice", open the problems for that stage in `practice/` and solve them.
4. Only when you've solved a problem (or tried for a long time), compare with `solutions/`.
